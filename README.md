# Adventure Card

Idle RPG mobile (F2P) avec exploration overworld et combats de cartes.
Nom de travail : **Adventure Card**. Univers/thème pas encore arrêté.

## Résumé rapide
- Deckbuilding : 3 personnages x 5 cartes = deck de 15 cartes (mélange unique, façon Slay the Spire)
- Combat : mode auto (idle, bot) et mode manuel (combats difficiles)
- Idle hybride : offline earnings + auto-battle foreground (écran allumé, façon Clash of Critters)
- Overworld façon Don't Starve, structure de campagne façon AFK Journey
- Roadmap : prototype PWA -> portage Godot/Unity, F2P
