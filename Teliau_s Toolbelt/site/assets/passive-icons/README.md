# Icônes de passif

Dépose ici les icônes que tu veux pouvoir attribuer aux passifs dans l'outil **Pet Builds**
(`site/pet-builds.html`).

- Formats acceptés : `.png`, `.jpg`, `.svg`, `.gif`, `.webp`
- Les fichiers de ce dossier apparaissent dans le sélecteur d'icône, à côté de chaque passif.
- Pour que le sélecteur visuel découvre automatiquement les fichiers, ouvre la page **via le
  serveur local** (`python3 -m http.server --directory site`, déjà configuré dans
  `.claude/launch.json`). Bouton **↻** dans le sélecteur pour rafraîchir après ajout.
- En `file://` (double-clic sur le HTML), la découverte auto ne marche pas : tu peux quand même
  taper le nom du fichier à la main dans le sélecteur.

Le dossier est pré-rempli avec les icônes de passif du jeu comme bibliothèque de départ.
